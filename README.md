## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/amaresharali17-coder/movie-explorer.git

# Navigate to project directory
cd movie-explorer

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Runs the app in development mode at `http://localhost:3000`.

### Production Build

```bash
npm run build
```

Generates optimized production assets in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
